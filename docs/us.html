日足のローソク足(1日の始値・高値・安値・終値)。緑=上昇(終値が始値より高い)、赤=下落。線は25日・75日の移動平均(終値の平均)で、価格がこの線より上か下かがトレンドの目安になります。

表示期間

① 騰落率は終了日基準(1日=前日比、1週=5営業日、1ヶ月=21営業日、3ヶ月=63営業日)。マスにマウスを乗せると、代表銘柄の変動率と変動幅(円/ドル)を表示します。代表銘柄は各セクターの時価総額上位から手動で選んだもので、ETFの公式な構成銘柄ではありません。

③ 流出額を流入セクターの大きさで按分した模式図です。実際の資金の行き先を示すものではありません。

④ 大きい点が終了日、線は直近8営業日の軌跡。時計回り(Improving→Leading→Weakening→Lagging)に循環するとされます。

出典・計算方法・注意事項

データの出典

  • 株価・売買高: Yahoo Finance(Pythonライブラリ yfinance 経由)。日足、分割・配当調整済みの終値、直近約1年。無料データのため遅延・欠損・訂正があり得ます。
  • セクター: Select Sector SPDR ETF(State Street)を各セクターの代理として使用。
  • 代表銘柄(ヒートマップのホバー表示): 各セクターの時価総額上位から手動で3銘柄ずつ選定(market_flow.py の REPS)。ETFの公式な構成銘柄・比率ではありません。株価はYahoo Finance。
  • ベンチマーク: S&P500(SPDR S&P 500 ETF)。
  • ETF発行口数: Yahoo Finance(get_shares_full と、実行日ごとのスナップショット)。リポジトリの data/shares_history.csv に蓄積。ETFの口数がYahooで未提供・更新が遅い場合は「近似」に自動で切り替わります。公式値(運用会社・取引所の公表)で補うときはこのCSVに date,ticker,shares で追記してください。
  • 最新データ日: 2026-11-27 ／ ページ生成: 2026-11-28 02:35 JST

計算方法

  • 実フロー = Σ(各日の発行口数の増減 × その日の終値)。設定(口数増)=流入、解約(口数減)=流出の推定。基準価額ではなく終値で評価するため誤差があります。
  • 近似フロー = Σ(各日の値上がり率 × 売買代金)、売買代金 = 終値×出来高。値動きと売買の勢いからの推定で、実際の資金流出入ではありません。
  • フロー% = 各セクターのフロー ÷ 全セクターの|フロー|合計。
  • サンキー図 = 流出額を流入セクターの大きさで按分した模式図。「AからBへ移った」という事実を示すものではありません。
  • RRG = 相対強度(セクター÷ベンチマーク、60日平均=100)とその10日モメンタム。
  • 保有銘柄のセクターは market_flow.py の STOCK_SECTOR で手動指定しています。
